# 圣剑之谎 · Lie in Stone

LLM 驱动 NPC 的社交博弈游戏（Godot 4 + GDScript，DeepSeek）。

圣剑在择主仪式上选中了你，但你知道自己没有神力。离出征讨伐魔王还有七天，你要靠说服、撒谎和坦白组建讨伐队。五名 NPC 由大模型扮演，夜里会互相传话，并当面拆穿你前后矛盾的说法。

## 设计要点

- **模型与规则分离**：模型输出结构化 JSON，代码校验之后才写入状态。动作有白名单，数值单轮限幅，结局由规则判定。
- **认知边界**：每个 NPC 只看到自己知道的事实、自己经历的对话和听来的传闻。
- **谎言台账**：记录玩家对每个人说过的话，夜间按人物关系图传播。

## 运行

1. 用 Godot 4.6 打开本目录。
2. 进入游戏后，在「连接设置」里填写 DeepSeek API Key。Key 保存在本机的 `user://secrets.cfg`，不会进入仓库。

自动测试（使用本地假模型，不需要 Key）：

```
godot --headless --path . -- --mock-llm --autotest
```
