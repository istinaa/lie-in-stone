# 《假勇者》Demo 验收说明

## 1. 怎么运行

1. 用 Godot 4.6（`E:\Godot\Godot_v4.6.2-stable_win64.exe`）打开 `E:\Hero\project.godot`，按 F5。
   或者直接在命令行运行：`E:\Godot\Godot_v4.6.2-stable_win64.exe --path E:\Hero`
2. 第一次进入时点「新的游戏」或「连接设置」，填写 DeepSeek API Key，点「测试连接」，成功后点「完成」。
   - Key 保存在 `%APPDATA%\Godot\app_userdata\假勇者 Demo\secrets.cfg`，不在项目目录里。
   - 也可以设置环境变量 `DEEPSEEK_API_KEY`（仍需点一次「测试连接」）。
   - 默认 Base URL 为 `https://api.deepseek.com`，模型为 `deepseek-chat`，都可以在设置里修改。

> ⚠ 开发时我手边没有可用的 Key，**真实 DeepSeek 接口没有实际联调过**。请求格式按 OpenAI 兼容的 Chat Completions 写成（`response_format: json_object`，提示词里带有“json”字样）。全部逻辑都已用本地假模型跑通（见第 4 节）。如果测试连接失败，界面会区分“网络问题”和“Key / 账户问题”，并显示服务端返回的错误信息。

## 3. 我替你做的决定（设计文档 12 节的待定问题）

1. **“凑齐讨伐队”的标准**：骑士团必须出兵（莱恩哈特加入）+ 必须掌握魔王弱点（奥斯瓦德加入，或从他那里问出弱点）+ 讨伐队至少 2 人。
2. **结局判定**（`scripts/rules/EndingRules.gd`）：
   - 第 8 天清晨选择跟诺娃走（需要她提出过带你逃跑）→ **逃兵**
   - 战力达标且队里至少 2 名共犯 → **众人之剑**
   - 战力达标但共犯不足 → **完美的谎言**
   - 战力不达标，且疑云 ≥ 70 或大祭司警觉 ≥ 80，且没有任何共犯 → **替罪羊**
   - 其他 → **壮烈殉国**
3. **第 3 天考验**：劈开包铁木桩。作弊路线需要事先让米娅或诺娃“答应暗中相助”（`promise_help` 动作），或让骑士知道真相并信任你。
4. **新增的小机制**：
   - 夜晚可以潜入神殿调查剑座。有诺娃帮忙就能拿到装置实证，没有的话会被大祭司察觉。
   - 傍晚以后可以在酒馆打听流言，看看哪些话已经传开了。
   - 诺娃信任 ≥ 45 时可能说出目击证词；奥斯瓦德信任 ≥ 60 时可能透露魔王弱点。
5. **字体**：用系统中文字体（微软雅黑优先），不打包像素字体，保证模型写出的任何字都能显示。

## 5. 建议的验收路线（每条大约 20-30 分钟）

- **坦白路线**：第 1 天下午去图书馆，找奥斯瓦德聊仪式的疑点，然后坦白 → 再去训练场向莱恩哈特坦白，并说出魔王弱点 → 请两人加入讨伐队 → 目标是「众人之剑」。
- **骗局路线**：一直对米娅吹神力，请她第 3 天帮你放光 → 考验过关 → 用神殿的权威说服骑士 → 目标是「完美的谎言」。
- **交易路线**：傍晚去酒馆找诺娃谈交易 → 夜里一起潜入神殿 → 第 8 天跟她走 → 目标是「逃兵」。
- **验证传话**：对米娅说“我的神力是冰冷的”，再对奥斯瓦德说“是温暖的”，第二天去图书馆，看他会不会拿这个质问你。

## 6. 文件结构

```
project.godot
data/            facts.json、locations.json、npcs/*.json（人设/初始值/日程/传话对象）、prompts/*.txt
scripts/autoload GameState.gd（时间/疑云/事件/存档）、LlmClient.gd（DeepSeek 请求/错误分类/统计）
scripts/npc      NpcState.gd、NpcBrain.gd（拼提示词/解析/重试/记忆压缩）、GossipSystem.gd
scripts/rules    DialogueRules.gd（限幅/阶段/白名单）、EndingRules.gd、Events.gd（预写剧情和考验）
scripts/ui       Main.gd（流程）、TownView、DialogueBox、StoryScreen、ApiSetup、InfoPanels、UiKit
scripts/dev      Autotest.gd（只用于开发）
tools/           gen_portraits.py、gen_town.py（占位美术生成）
```

## 7. 已知限制 / 下一步

- 没有用真实 DeepSeek 联调过，第一次跑真实接口时，建议留意提示词效果和数值平衡（比如说服的难度）。
- 角色不会在地图上走动，地点用热区点击（M0 够用，还没做行走）。
- 对话是整段返回，不是逐字流式输出。
- 结局只看代码状态，“众人之剑”里“公开真相”这一步暂时简化为“至少 2 名共犯随行”。

## 9. 试玩反馈后的改动（2026-11-15 晚）

详见 `docs/试玩反馈分析.md`。概要：

- **心结 + 线索卡 + 邀请加入**：每个人有 1~2 个由代码判定的心结，解开后才能邀请加入讨伐队；对话里可以出示线索卡。数据在 `data/npcs/*.json`（dossier / goals）和 `data/clues.json`，逻辑在 `scripts/rules/GoalSystem.gd`。
- **引导**：地图右上角「接下来」面板、地图提示、手记的「目标 / 线索 / 人物档案」。
- **反馈**：对话中的信任 / 怀疑条、每轮的变化提示、离开时的谈话小结。
- **对话记录**：对话界面的「对话记录」按钮；打开对话时显示上次谈话的最后几句。
- **LLM**：先写 understanding 再写台词；去 AI 腔的说话规则；新增 impression 字段；temperature 0.8。F1 调试面板会显示模型对你这句话的理解。
- **F1 调试面板默认关闭**（之前默认打开）。
- **打包**：`E:\Hero_build\假勇者.exe`（另见该目录的运行说明）。
- 自检：`--mock-llm --autotest` 共 79 项。
