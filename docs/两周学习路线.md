# 两周学习路线：LLM/Agent 实习冲刺（2026-11-17 起）

**目标：** 两周后，既能讲清楚 LLM 从训练到推理的底层原理，又能把《假勇者》讲成一个有数字支撑的 Agent 项目，经得起技术面五层追问。

**主线：** 底层（MiniMind 从 0 训练） → 应用层（提示词、Agent、记忆、RAG） → 项目落地（Python 化、评估） → 面试打磨。

**原则：**
- 每个概念都要回到代码：MiniMind 里在哪一行，或者《假勇者》里在哪、为什么没用。
- 每天结束时写一篇学习笔记（`notes/dayXX.md`），用自己的话回答当天的"自测题"。答不出的地方就是第二天的复习内容。
- 训练跑起来以后就在后台挂着，同时做阅读，不要干等 GPU。

## 第 0 天（开始前的晚上，约 2 小时）：准备环境

**本机配置：** RTX 4050 Laptop，6 GB 显存。系统 Python 是 3.13，还没装 PyTorch。

- [ ] 装 Miniconda，新建独立环境。Python 版本按 MiniMind README 的要求来，一般 3.10/3.11 最稳，不要用系统的 3.13。
- [ ] 安装 CUDA 版 PyTorch，验证 `torch.cuda.is_available()` 为 True。
- [ ] clone `jingyaogong/minimind`，通读 README，下载预训练和 SFT 用的数据集（文件很大，先挂着下载）。把《假勇者》初始化成 git 仓库，做第一次提交（`.godot/`、截图目录加进 `.gitignore`）。
- [ ] 准备 DeepSeek API Key（第 5 天要用）。

**关于显存：** MiniMind 的最小模型（约 26M 参数）在 6 GB 显存上能训，需要调小 `batch_size` 并配合梯度累积，精度用 bf16（40 系显卡支持）。笔记本跑完整预训练可能要几个小时，**适合挂一整晚**。如果嫌慢，可以在 AutoDL 之类的平台租一张 3090/4090，按小时计费，成本很低。

## 第一周：从 0 训练 LLM，再上到应用层

### 第 1 天：读懂模型结构
**学：** 分词器（BPE）→ Embedding → **RMSNorm** → **RoPE 位置编码** → **自注意力**（因果掩码、多头、GQA）→ **FFN（SwiGLU）** → 残差与 Pre-Norm → LM Head。MiniMind 的结构与 Llama 类似，看懂它就等于看懂了主流架构。
**做：**
- [ ] 逐行读模型定义文件，在关键张量处标注形状，例如 `[batch, seq, n_heads, head_dim]`。
- [ ] **不看代码，自己手写一遍单头和多头注意力**，与原实现对拍输出。
- [ ] 算一遍参数量：按配置手算，再和代码打印的结果对照。
- [ ] 晚上启动预训练，挂一整夜。
**自测：** 为什么要除以 √d？因果掩码怎么实现？RoPE 为什么能表达相对位置？GQA 省的是什么？Pre-Norm 和 Post-Norm 有什么区别？

### 第 2 天：预训练与推理
**学：** 下一个 token 的交叉熵损失、学习率 warmup 加余弦衰减、混合精度、梯度累积、梯度裁剪。推理侧：自回归生成、**KV Cache**、采样方法（greedy、temperature、top-k、top-p）。
**做：**
- [ ] 看 loss 曲线，记录训练速度（tokens/s）和显存占用。
- [ ] 用预训练模型续写文本，体会"只会接话、不会对话"。
- [ ] **自己实现一遍采样函数**，比较不同 temperature 的输出。
- [ ] 对比开、关 KV Cache 时的生成速度。
**自测：** KV Cache 存的是什么，为什么能加速？显存随什么增长？**前缀缓存（Prompt Caching）和 KV Cache 是什么关系？**（这题直接关联《假勇者》中"system prompt 固定"的设计。）temperature 0.8 意味着什么？

### 第 3 天：SFT 与 LoRA
**学：** 对话模板（chat template）、**只对回答部分计算 loss**（loss mask）、全量微调和 LoRA 的区别（低秩分解、插在哪、秩 r 和 alpha 各起什么作用）。
**做：**
- [ ] 跑完 SFT，让模型会对话。
- [ ] 用 LoRA 在一个小领域数据上微调。可以自己造几百条"假勇者 NPC 风格"的对话，体会"微调改风格"的效果。
- [ ] 对比 SFT 前后、LoRA 前后的输出。
**自测：** SFT 的 loss 为什么要 mask 掉用户部分？LoRA 为什么能省显存？什么时候该微调、什么时候改提示词就够？（面试官可能会问：为什么《假勇者》不微调 NPC？）

### 第 4 天：对齐、蒸馏与收尾
**学：** RLHF 的流程（奖励模型 + PPO）、**DPO** 的思路（不用奖励模型，直接用偏好对优化）、知识蒸馏、推理模型（长思维链）的大致训练思路。MiniMind 里有哪些就跑哪些，没有的只需理解概念。如有余力，再看 MoE 变体。
**做：**
- [ ] 跑一次 DPO，看偏好数据的格式。
- [ ] 写一篇总结笔记《从 0 训练 LLM 全流程》，配一张"预训练 → SFT → LoRA → DPO"的流程图。**这篇笔记本身可以放进简历附带的 GitHub。**
**自测：** DPO 和 PPO 的核心区别？幻觉从哪来？为什么对齐会带来"对齐税"？MoE 省的是什么，代价是什么？

> 第 4 天结束时要能讲清楚：一个 token 从输入到输出经过了什么，一个模型从随机初始化到能对话经过了什么。

### 第 5 天：提示工程与结构化输出 + 接通真实 API
**学：** system/user/assistant 的角色分工、few-shot、CoT、**JSON mode、约束解码、function calling 的原理**（结合第 2 天的采样知识：约束解码就是在采样前屏蔽不合法的 token）。
**做（《假勇者》）：**
- [ ] 接通 DeepSeek API，真实跑完一局。
- [ ] 加调用追踪：每次调用写一行 JSONL，记录提示词、输出、延迟、token 数、缓存命中、重试次数、规则层拦截了什么。
- [ ] 从真实日志里挑出 3 个坏案例，记进《失败案例》文档。
**自测：** 为什么《假勇者》要把 system prompt 设计成固定的？JSON 输出坏了有几种处理办法，各自的代价是什么？

### 第 6 天：Agent 范式与多智能体
**读：** Anthropic《Building Effective Agents》、Lilian Weng《LLM Powered Autonomous Agents》、*ReAct*、*Reflexion*。了解 AutoGen、CAMEL、LangGraph 的大致思路，以及 MCP 是什么。
**做：**
- [ ] **精读 *Generative Agents* (Park et al., 2023)**，逐条对照《假勇者》：记忆流 ↔ `memory_summary`，反思 ↔ ？，规划 ↔ ？，信息传播 ↔ `GossipSystem`。差距就是改进点。
- [ ] 画出《假勇者》一轮对话的完整数据流图（README 要用）。
**自测：** 工作流（workflow）和 Agent 的区别是什么？《假勇者》属于哪一种？为什么数值判定不交给模型？

### 第 7 天：记忆与 RAG
**学：** 短期和长期记忆、摘要压缩、向量检索（embedding、相似度、向量库）、切块、混合检索、rerank、RAG 常见的失败模式；*MemGPT* 的分层记忆；*Lost in the Middle*。
**做：**
- [ ] 用 Python 做一个最小 RAG：几十条文本，embedding 后检索。用开源 embedding 模型或 API 都行，1～2 小时内完成，只为理解原理。
- [ ] 为《假勇者》设计"事件记忆 + 检索"方案（按重要度 × 时近性 × 相关性打分），先写文档，第 9 天实现。
**自测：** 什么时候该用 RAG，什么时候该用长上下文？现在的摘要式记忆会丢什么？
