## 1. 统一规格（从已有图片归纳）

已有的图风格比较统一：**半写实日系厚涂，有轻微的像素颗粒感**，色调偏暗、暖，中世纪奇幻服饰。后面的图建议保持这种风格。

| 项目 | 规格 |
|---|---|
| 立绘构图 | 半身到大腿，正面或 3/4 侧身，**头部在画面上方 1/4 以内**（游戏会从这里裁小头像） |
| 立绘比例 | **2:3**。目前有两种尺寸：1248×1872（大祭司、奥斯瓦德、诺娃、候选勇者）和 1024×1536（米娅、莱恩哈特、国王、间谍）。比例相同就能正常显示，以后统一用 1248×1872 即可。奥斯瓦德原图是 1248×1820，游戏里会上下留一点空，不影响使用 |
| 立绘背景 | 透明 PNG（已有的都是透明的 ✅）。米娅和莱恩哈特身后带一圈暗色光晕，其他人没有，可以统一一下（不急） |
| 场景背景 | 16:9，2048×1152 或 1920×1080，不带人物，**必须完全不透明** |
| CG | 16:9，1920×1080，可以带人物 |
| 道具图标 | 正方形，256×256，透明背景，同一个光照方向 |

### 游戏里的显示方式
- 对话界面左侧显示整张立绘，大约 260×390 像素。
- 地图名牌、地点列表、手记里的小头像（34~72 像素）是**自动从立绘里裁出来的头部**，裁切位置在 `assets/portraits/portraits.json` 里调（`face` = 中心 x、顶部 y、边长，都是相对比例）。新立绘如果头的位置不一样，改这里就行。
- 主角输入框旁边的 44 像素小头像同样从主角立绘里裁切。

### 怎么替换或新增
| 内容 | 放到哪里 |
|---|---|
| 角色立绘 | `assets/portraits/<角色id>.png`（id 见下表），并在 `portraits.json` 里加一行裁切位置 |
| 地点背景 | `assets/backgrounds/<地点id>.png`；夜晚专用图可以另放 `<地点id>_night.png`，没有时程序会自动把白天图调暗调蓝 |

放进去以后用 Godot 打开一次项目，让它导入图片即可，不用改代码。（建议在导入设置里勾选 Mipmaps，缩小显示时更清晰；现有的图已经勾上了。）

#### 主角设定（供绘制参考）
- **20 岁左右的男生**。神殿后厨的杂役，孤儿，没有姓氏，连名字都是老厨娘随口起的。
- 仪式当天被临时套上一身**不合身的勇者礼服**：衣服明显偏大，袖口挽起，腰间挂着那把圣剑（不发光）。
- 体型偏瘦，干惯了粗活，手上有茧。气质普通，眼神里有慌张也有倔强。
- **不能画得像天选之人**。候选勇者（`候选勇者.png`）也是棕发、偏冒险者的打扮，主角要和他拉开差别，比如发色、体态，或者更“穿不惯”的礼服。
- 只画一张，表情建议用略带紧张的平静，开场、夜间结算、结局都通用。
