### LLM 的修改
诺娃那段的问题：你说“**他**问我圣剑认主时有什么感觉”是在回答她的问题，“他”指大祭司；模型却理解成你在问她。原因有两个：
1. 你的这句话放在一大段状态描述的最后，模型要同时填十几个 JSON 字段，没有“先理解再回答”的步骤；
2. 提示词里没有把“NPC 上一句”和“勇者这一句”放在一起，模型看不出这是问答关系。

改动：
- JSON 第一个字段改成 `understanding`：模型先用一句话写出“勇者这句话的意思、是不是在回答我、‘他’指谁”，再写台词。按 F1 打开调试面板，对话界面左上角会显示这句理解，方便你判断是不是理解错了。
- 提示词末尾改成「你刚才说的：……／勇者接着对你说：……」，问答关系一目了然。
- 新增“先听懂，再开口”和“说话要像真人”两组规则：一次只回应一件事、80 字以内；禁止排比、“第一、第二”式列点、连续反问、堆砌成语和书面词、说教总结；动作括号最多一个。
- temperature 从 1.0 降到 0.8，减少跑题。

> 仍需你用真实 Key 再试一次。如果诺娃这类误解还在，下一步可以把对话改成多轮 messages（每句台词一条消息），或试试更强的模型。

## 第 1、2 条：为什么“没信息、没目标、不好玩”

### 原因
1. **空白页问题**。自由输入要求玩家自己想话题，但玩家几乎不知道对面的人想要什么、知道什么、怕什么。人设里写好的“动机”和“秘密”，玩家看不见，也没有可靠的途径打听到。推荐说法又比较泛（“请相信我”），帮不上忙。
2. **目标抽象，路径不可见**。“凑齐讨伐队”只有三行检查项，至于“怎样才能让莱恩哈特加入”，取决于隐藏的信任阈值和模型临场选的 action。玩家既看不到路，也不知道自己离目标还有多远。
3. **没有反馈回路**。一次谈话说了 8 句，结束后看不出有没有进展：数值只在调试面板里，态度阶段很少变化，传话效果要到夜里才出现。行动和结果之间没有可感知的因果，自然就没有动力。
4. **玩法动词太少**。整个游戏只有“谈话 / 休息 / 两个地点行动”，而且谈话的结果主要靠模型发挥。核心乐趣（装神弄鬼、圆谎、被拆穿的紧张感）只在第 3 天考验时集中出现一次。
5. **模型不稳定会放大以上问题**。玩家本来就缺信息，模型再答非所问，玩家会觉得“怎么说都一样”。

### 改进方案（按性价比排序）

| # | 方案 | 解决什么 | 工作量 |
|---|---|---|---|
| A | **人物档案和诉求**：第一次见面后，手记里显示这个人“想要什么 / 在意什么 / 讨厌什么”（逐步解锁），以及“怎样才可能让他加入”的提示 | 1、2：知道该聊什么 | 小 |
| B | **每次对话的可见反馈**：每轮回复后显示一行非数字的变化提示（如“莱恩哈特更怀疑你了——你在回避他的问题”），关系用看得见的条形或刻度表示，谈话结束时给一个小结 | 3：行动有回响 | 小 |
| C | **主线任务和每日提示**：把目标拆成具体的下一步（“去训练场见莱恩哈特，他明天要考验你”），预告接下来的事件，完成时有明确的提示 | 2：目标感 | 中 |
| D | **线索 / 证据卡**：从对话、流言、调查中获得“线索卡”（如“大祭司问了三遍感觉”“诺娃见过装置”），对话时可以“出示”给对方，每张卡在特定的人面前有明确作用 | 1、4：给玩家具体的手段，减少空白页 | 大 |
| E | **每个 NPC 一个小目标**：比如“回答出奥斯瓦德关于仪式的三个疑点”“给诺娃凑够 50 金币”“在莱恩哈特面前拿出作战计划”，由代码判定，模型负责表演 | 2、4：把聊天变成可解的小谜题 | 大 |

建议先做 **A + B + C**（改动小、见效快），试玩后再决定要不要做 D / E。

## 实施情况（2026-11-15，A~E 全部完成）

### A. 人物档案
- 手记 → 人物：每个人有「传闻 / 想要 / 讨厌 / 喜欢」。传闻一开始就知道；见过面后解锁“想要”和“讨厌”；认真聊过一次（说了至少 2 句）后解锁“喜欢”。
- 地点界面里，每个人下面会显示一行：没见过面时是传闻，见过后是他当前的心结。
- 地点界面还会列出“其他时段常来这里的人”，不用再到处碰运气。

### B. 可见的反馈
- 对话界面左下角：信任 / 怀疑两条进度条（大祭司是“掌控 / 警觉”），随每一轮变化。
- 每轮回复后多一行反馈：如「◇ 信任↑ 怀疑↓↓　“总算说了句实在话”」。箭头数量表示幅度，后半句是对方的感受（模型新增的 impression 字段）。
- 离开对话时弹出“谈话小结”：信任 / 怀疑的变化（略微 / 明显 / 大幅）、态度变化、对方记下了你几句话（会不会被传出去）、本次获得的线索和完成的目标、这个人的下一步。

### C. 任务与引导
- 地图右上角「接下来」面板（可收起）：即将发生的事件（如“明天下午：骑士团的公开考验”）+ 每个关键人物的下一步（做什么、去哪里找他）。
- 完成目标、获得线索时，回到地图会弹出提示。
- 开场的“你的目标”页改写了，介绍心结、线索和「接下来」面板，并建议第一步先去图书馆找奥斯瓦德。

### D. 线索卡
- 6 张卡（`data/clues.json`）：大祭司的“关照”、神殿的津贴、仪式的疑点、诺娃的证词、符文核心、古籍里的弱点。
- 对话里点「出示线索」选一张卡给对方看（输入框里的话会一起说出去）。每张卡对每个人的反应和数值变化都写在数据表里，由代码执行，模型只负责演出来。同一样东西给不同的人看，效果可能完全相反（比如符文核心给奥斯瓦德是好事，给米娅会让她崩溃，给大祭司是找死）。
- 手记新增「线索」页。

### E. 每个人的心结（代码判定的小目标）
| 人物 | 心结 | 解开后 |
|---|---|---|
| 莱恩哈特 | ① 看到你的诚意或本事（考验过关，或向他坦白）② 拿出作战计划（出示「古籍里的弱点」） | 可以邀请加入 |
| 奥斯瓦德 | ① 解答仪式的疑问（坦白，或出示「诺娃的证词」「符文核心」）② 讨伐有胜算（莱恩哈特已加入） | ① 告诉你魔王的弱点；全部解开后可以邀请加入 |
| 诺娃 | ① 相信你不是神殿的同伙（坦白，或出示「大祭司的“关照”」）② 付她报酬（给她「神殿的津贴」） | ① 给你她的证词；② 答应暗中帮你 + 出城退路 |
| 米娅 | ① 认真对待她（好好聊两次）② 赢得真正的信任（坦白后她仍信任你，或多聊、一直真诚） | ① 答应用光魔法帮你 |

- 线索之间是连起来的：大祭司召见 → 拿到“关照”和钱 → 找诺娃换证词 → 证词给奥斯瓦德换弱点 → 弱点给莱恩哈特 → 莱恩哈特加入 → 奥斯瓦德也愿意去。也可以全程靠坦白走另一条路。
- 「邀请加入讨伐队」是对话里的一个按钮。答不答应由代码判定（心结是否全部解开）：解开了就一定答应；没解开时，对方会拒绝，并让你听出他还在等什么。模型不能再自己决定加入。
- 模型每轮都会收到【你心里的盘算】（当前心结），所以角色会在聊天中自然地透露他想要什么。
